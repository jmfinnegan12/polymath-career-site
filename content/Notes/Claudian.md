# Claudian

Claudian is a beta Obsidian plugin that embeds Claude Code inside the Obsidian vault. The vault becomes the agent's working directory — file read/write, search, bash, multi-step workflows all available without leaving Obsidian.

Repo: https://github.com/YishenTu/claudian

I use it as the AI layer of my planning and project management stack. Combined with OpenWhispr for voice capture, it has become how I plan weeks, manage projects, draft posts, and update my calendar.
